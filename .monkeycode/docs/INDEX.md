# link_equipment 文档

## 项目概述

link_equipment 是一个面向智能家居 / 消费级设备的接入管理平台，以「Web 管理后台 + 移动端（uni-app / 小程序）」双形态交付，帮助平台自营团队统一完成设备配网、设备生命周期管理与设备数据可视化。

**目标用户**：
- 终端用户 / 客户：在自己的家庭空间内添加设备、查看设备状态与数据。
- 平台管理员：维护产品与物模型、管理设备台账、查看运营数据看板。

**核心价值**：
- 统一接入入口：SoftAP / 蓝牙配网完成设备入网，MQTT 长连接承载设备上行数据。
- 物模型驱动：以产品与物模型定义设备能力，设备类型扩展时无需改动核心链路。
- 数据可视：设备在线状态、关键指标看板与历史数据报表，支撑日常运营。

## 技术选型

| 类别 | 选择 | 理由 |
|------|------|------|
| 后端语言 / 框架 | Python + FastAPI | 开发效率高，异步模型契合 MQTT 接入与高并发查询场景 |
| Web 管理后台 | Vue 3 + Vite + Element Plus | 中后台组件生态成熟，构建速度快 |
| 移动端 | uni-app / 小程序 | 一套代码覆盖小程序与 App，配网引导复用成本低 |
| 数据库 | MySQL | 存储产品、物模型、设备、用户等关系型元数据 |
| 缓存 / 会话 | Redis | 缓存设备在线状态、登录会话与热点看板指标 |
| 设备接入 | MQTT Broker（EMQX / Mosquitto） | 消费级设备主流接入方式，天然支持长连接与上下行 |
| 配网方式 | SoftAP / 蓝牙 | 面向 Wi-Fi / 蓝牙消费级设备的入网引导 |
| 认证 | 账号 + 密码（JWT） | 终端用户与管理员统一登录模型，无状态易扩展 |
| 部署 | Docker Compose | 一键拉起应用、数据库、缓存与 Broker，兼顾开发与上线 |

## 核心功能

### 设备接入与生命周期
- **目的**：让设备可被安全地发现、配网、注册并持续可用。
- **描述**：通过 SoftAP / 蓝牙配网会话引导设备入网，配网成功后设备以设备凭证连接 MQTT Broker；平台维护设备从「未激活 → 已激活 → 在线 / 离线 → 已禁用」的状态流转，并支持设备与家庭空间的绑定关系。

### 产品与物模型管理
- **目的**：用一套与设备类型无关的模型描述设备能力。
- **描述**：管理员创建产品并定义物模型（属性、事件、服务），物模型以 JSON 描述数据类型、读写权限与取值范围，作为设备上报校验、指令下发和看板指标生成的统一依据。

### 数据看板与报表
- **目的**：把设备运行数据转化为可读的运营视图。
- **描述**：消费 MQTT 上行遥测数据并落库，提供设备在线率、活跃设备数等概览指标，以及按设备 / 时间段查询历史数据的能力，支持报表导出。
